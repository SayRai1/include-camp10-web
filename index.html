ตั้งค่าที่เก็บข้อมูล (ทำครั้งเดียว)

ใช้ Firebase เป็นที่เก็บคะแนนกลาง ฟรี 100%
ทุกคนจะเห็นคะแนนตรงกันแบบเรียลไทม์

  1. เปิด console.firebase.google.com → Create a project → ตั้งชื่อ (เช่น include-camp-10) → ปิด Analytics ได้ → Create
  2. เมนูซ้าย Build → Firestore Database → Create database → location asia-southeast1 → Start in test mode → Enable
  3. แท็บ Rules → วางโค้ดนี้ → Publish: rules_version = '2'; service cloud.firestore { match /databases/{db}/documents { match /camp/data { allow read, write: if true; } } }
  4. ⚙️ Project settings → Your apps → ไอคอน </> (Web) → ตั้งชื่อ → Register app
  5. คัดลอกก้อน firebaseConfig มาวางข้างล่าง 👇

config จะถูกจำไว้ในเครื่องนี้ · ถ้าอยากให้ทุกคนใช้ได้ทันที ให้ใส่ใน FIREBASE_CONFIG ในไฟล์ก่อน deploy
