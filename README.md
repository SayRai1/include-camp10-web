# INCLUDE Camp 10 Web App

Interactive web app made for **INCLUDE Camp 10**, a camp run by the Department
of Control Systems and Instrumentation Engineering (INC), KMUTT, where I was
project president.

![HTML](https://img.shields.io/badge/HTML-E34F26?logo=html5&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

## Features

- "Memory orb" activity where campers leave messages and memories
- Shared online storage, set up once by the staff
- Mobile-first layout, so campers use it on their own phones

## Run

Open `index.html`, or host it on GitHub Pages.
